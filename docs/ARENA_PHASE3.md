# Phase 3 arena art

The eight supplied `ENV_P3_*` images live in `Assets/Resources/ArenaArt/Landmarks`. `ArenaLayout.json` defines their size, ground position and occupied cells. Seven structures block their bases; `LastHabitatPatch` only blocks the central rock and leaves the rest of its depicted ground walkable. `ArenaAuthoring.BuildLandmarks` uses the same masks for the simulation and `BoxCollider2D`, with bottom-pivot sprites and soft contact shadows. Tall artwork fades when it obscures the player.

Phase 3 uses the continuous `FloorIndustry` and `DetailIndustry` ground: broken concrete, broad lanes, service cables and sparse overgrowth match the supplied human-base art without a repeating tile pattern. The props are arranged around those open lanes, with the command pod near the north side and the habitat patch on the southeast side. The two shops are now on opposite sides of the arena at `(-19, -4.5)` and `(19, 4.5)`; their scene markers, kiosks, source defaults and baked collision cells match.

Static validation checked every new occupied cell against existing phase-three blockers and flood-filled walkable cells from the player start in all three phases. Both shops are reachable in each phase. For visual review, enter Play Mode from `MainMenu`, continue a phase-three save or progress to phase 3, walk around each new structure, and confirm that its base stops movement while the upper artwork fades when the player passes behind it. Also visit both shops in each phase. EditMode test execution was attempted but Unity CLI reported this project already open in another Editor.

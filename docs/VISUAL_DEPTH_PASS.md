# Hollow visual depth pass — 2026-10-17

## هدف و شواهد

پنج اسکرین‌شات Unity ارسالی نشان می‌دهند که درخت، بازیکن، اپراتور و کیوسک شخصیت دارند؛ اما تکرار ۸×۸ زمین، لکه‌های درشت تیره، اختلاف کم رنگ فازها و اشیای placeholder مستطیلی از عمق صحنه کم می‌کنند. در نبرد باس صنعتی، هشدار قرمز باید با شلوغ شدن تصویر همچنان واضح بماند. مطابق GDD v0.19، تغییر حال‌وهوای هر فاز نباید دید مبارزه را خراب کند.

نمونه‌های مقایسه: Kill the Crows برای سادگی و خوانایی میدان مبارزه، Hades برای تفکیک شخصیت/محیط با رنگ و نور، و The Ascent برای چراغ‌های موضعی صنعتی. این‌ها جهت طراحی‌اند، نه الگوی کپی آرت یا تغییر دوربین.

## تغییر انجام‌شده

- رنگ نور 2D، کنتراست، کاهش اشباع و تیرگی نرم گوشه‌ها برای هر فاز جدا شد. دوربین و زاویه‌اش تغییر نکرده است.
- Bloom کم‌قدرت روی دوربین دنیا فعال شد؛ UI از آن عبور نمی‌کند. چراغ آبی‌فیروزه‌ای ملایم کنار دو کیوسک فروشگاه قرار گرفت.
- روشنایی زمین با نویز نرم و غیرتکراری اندکی تغییر می‌کند تا کاشی ۸×۸ دقیقاً در هر بلوک یکسان دیده نشود. شدت آن تنظیم‌پذیر است؛ این کار جایگزین آرت زمین متنوع نیست.
- پنجرهٔ `Hollow > Visual Tuning` اسلایدر و رنگ‌گزین هر فاز را دارد. `Apply to running game` نتیجه را هنگام Play نشان می‌دهد؛ `Save as default` آن را در `Baseline.json` برای اجراهای بعد ذخیره می‌کند. `Reset to suggested look` مقادیر این پاس را برمی‌گرداند.
- گزینهٔ حذف shader variantهای استفاده‌نشدهٔ Post Processing در URP خاموش شد، چون Volume این بازی هنگام اجرا ساخته می‌شود. این کار ممکن است اندازهٔ build را کمی بالا ببرد.

## آزمون در Unity

1. بگذارید Unity اسکریپت‌ها را import و compile کند؛ Console باید بدون خطای C# باشد.
2. از منوی `Hollow > Visual Tuning` پنجره را باز کنید. Game view را کنار آن قرار دهید.
3. Play را بزنید و وارد بازی شوید. در تب Forest، `Ambient light color`، `Ground mist` و `Ground variation` را یکی‌یکی تغییر دهید و هر بار `Apply to running game` بزنید. تغییر باید بدون شروع مجدد بازی دیده شود.
4. کنار یک کیوسک بروید: زمین اطراف صفحهٔ آن باید کمی نور فیروزه‌ای بگیرد. با زیاد و کم کردن Bloom ببینید نوشته‌ها و نشانهٔ خطر واضح می‌مانند.
5. با پنل F10 به فاز صنعتی و پایگاه انسانی بروید و تب همان فاز را تنظیم کنید. در نبرد شلوغ، بازیکن، اپراتور، دشمن، سکه و تلگراف حمله را در اندازهٔ واقعی Game view بررسی کنید.
6. اگر نتیجه مناسب بود `Save as default` را بزنید، Play را متوقف و یک بازی تازه شروع کنید؛ تنظیمات باید باقی باشند. برای مقایسه `Reset to suggested look` و سپس Apply را بزنید.

## کار هنری باقی‌مانده

تکرار شکل‌های مشخص داخل تصویر ۸×۸ هنوز تا حدی دیده می‌شود. برای رفع واقعی آن، حداقل دو ورژن tileable با همان پالت برای هر فاز و چند لکهٔ زمینِ مستقل لازم است. مستطیل‌های بدون جزئیات در تصاویر فاز صنعتی هم placeholder اشیایی هستند که آرت نهایی ندارند. این پاس نور آن‌ها را به شیء واقعی تبدیل نمی‌کند. بعد از دریافت آرت جایگزین، پیش‌فرض‌های نور و کنتراست باید دوباره در Play Mode تنظیم شوند.

## محدودیت تأیید

اسمبلی‌های Data، Presentation، Game، Editor و Tests.EditMode با کامپایلر Unity کامپایل شدند و JSON معتبر است. Unity Test Runner از CLI به‌علت باز بودن پروژه در Editor اجرا نشد؛ ظاهر افکت‌ها هنوز در Play Mode بررسی نشده است.
